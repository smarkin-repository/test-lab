# Голос — тетрадь упражнений

Автономный редактор вокальных упражнений на русском языке. Откройте `index.html` в современном браузере или разместите папку на статическом хостинге. Сборка и зависимости не нужны.

- Текст/слог над каждой нотой; диапазон A2–A5, включая диезы.
- Длительности 1/16, 1/8, 1/4, 1/2, целая; паузы; перестановка и дублирование нот.
- Прослушивание синтезированным звуком, темп 30–240 BPM, повтор, транспонирование.
- Несколько упражнений; автосохранение в localStorage; экспорт/импорт JSON; печать/PDF.

Данные хранятся в конкретном браузере, без серверной синхронизации. Для переноса на другое устройство скачайте JSON и откройте его в редакторе. Проигрывание останавливается при уходе со вкладки.

Это буквенная запись упражнений, без пятилинейного нотного стана. Синтезатор проигрывает высоты нот, не произносит слоги.

Проверены синтаксис JS, соответствия MIDI/нот, диапазон, проверка импорта, длительности и экранирование текста. Проверка интерфейса и аудио в браузере в этой среде не выполнялась.

Исходники в этой папке можно размещать независимо от Sites. Автоматическая публикация из GitHub в Sites не настроена.
